# CEISCaramulo

Website institucional do CEISCaramulo com frontend nextjs e base de dados PostgreSQL via Prisma.

## Scripts

- `npm run dev`: arranca frontend e backend em paralelo
- `npm run build`: gera a build de produção do frontend
- `npm run prisma:migrate`: cria e aplica migrações Prisma
- `npm run prisma:seed`: popula a base de dados com conteúdo inicial

## Áreas principais

- Website público com notícias, atividades, projetos e biblioteca
- Backoffice com autenticação Neon Auth
- Conteúdo rich text com media embebida
- Comentários públicos por conteúdo
